# 环境检查提示

在 `~/lab1/` 里启动 `claude`，把下面这段粘贴进去：

```
请帮我检查本机的研究环境，只检查、不安装任何东西：
1. 报告操作系统和当前工作目录；
2. 检查 python / python3 是否可用，报告版本；
3. 检查 R 是否可用（Rscript --version）；
4. 检查 Stata 能否从命令行以批处理方式运行；如果找不到，告诉我在我的系统上
   一般会装在哪里、应该怎样调用，但不要修改任何系统设置；
5. 检查 git 是否可用；
6. 最后用一张表总结：工具、是否可用、版本、如果不可用下一步该做什么。
```

**注意**：它可能会请求运行命令的权限。这是正常的，读清楚它要运行什么命令再同意。
