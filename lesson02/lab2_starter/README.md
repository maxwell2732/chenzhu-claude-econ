# 第 2 课 Starter Pack：从一个模糊的想法到一张可用在论文中的图表

《朱晨的 AI 智能体课：Claude Code 经济学研究实战》· 朱晨 · 中国农业大学经济管理学院

第 2 课的课后作业约 2 小时，自学完成，不需要提交。第一次做的同学，先看 `第2课课后作业使用说明.pdf`。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `第2课课后作业使用说明.pdf` | 图文版操作说明，先看这份 |
| `lab2_handout.md` | 作业说明（文字版） |
| `lab2_verify_checklist.md` | 验收清单，做完逐项自查 |
| `opening_prompt_template.md` | 六个部分的开场提示模板，社媒版和世界银行版各一份 |
| `clarify_prompts.md` | 澄清问题用的三套提示（深度、广度、高度），以及动手前给计划挑毛病的压力测试提示 |
| `collection_rules.md` | 社媒数据采集规则，复制进 CLAUDE.md |
| `CLAUDE.md.template` | 本课项目的 CLAUDE.md 模板 |
| `gitignore.txt` | 改名为 `.gitignore`，防止原始数据和登录信息进入 Git |
| `setup_browser.md` | 让智能体操作浏览器：Playwright MCP 或 Claude in Chrome |
| `DATA_PROFILE_template.md` | 数据画像模板 |
| `COLLECTION_LOG_template.md` | 采集记录模板 |
| `README_template.md` | 项目 README 模板（含两个检查） |
| `clean_comments_example.py` | 参考清理脚本：去重、时间换算、去标识化。先让智能体自己写，再对照 |
| `download_wdi_structural.py` | 基础档参考脚本：下载农业就业占比和人均 GDP |
| `exit_ticket.md` | 课后 exit ticket |

## 数据说明

- 基础档只用世界银行公开数据，不需要登录任何平台。
- 标准档和进阶档采集的社媒数据，只用于个人学习和研究。原始数据只留在你自己的电脑上，不上传、不分享。
- 第 3 课要用 CHNS 或 CHARLS，课程不分发任何数据，请自行申请下载。
