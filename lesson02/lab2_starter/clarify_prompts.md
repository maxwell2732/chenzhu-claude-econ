# 澄清问题用的三套提示

适合在你已经描述了关心的议题、手上有什么数据之后使用。三套提示都要求智能体先别替你回答。把【你的领域】换成你自己的研究领域。

---

## 增加研究深度

```
我现在知道我想解决什么问题了，但我还不知道怎样才能把它做得足够深入。

请先不要直接解决。先带我判断：
1）我目前对这个问题的理解处于什么层次？
2）一个【你的领域】的顶尖专业人士，会比我多考虑哪些东西？
3）我目前看到的信息中，哪些已经是别人加工过的，哪些是最原始的数据或事实？
4）要深入这个问题，需要哪些专业方法、工具、数据或实验？
5）我目前有哪些未经验证的假设？
6）哪些假设最值得优先挑战？
7）有没有可能从现有信息中发现我原本不知道的新问题或新规律？
8）最终应该用什么方式验证我们的结论？

请不要替我假设答案。
如果你发现我缺少关键背景信息，请告诉我缺什么，并解释为什么重要。
先带我建立如何深入这个问题的地图，再开始真正解决问题。
```

## 增加研究广度

```
我知道自己想解决什么问题，但我很可能被自己所在经济学领域的思维方式限制了。

请先不要直接解决我的问题。

先作为一个跨领域探索器，帮助我寻找可能被我忽略的解决路径：

1）先把我的问题抽象成更底层、更通用的问题，不要局限在我现在使用的专业术语里。
2）分析这个问题的核心结构是什么。
3）寻找其他领域中是否存在结构相似的问题。
4）给出 3～5 个最值得探索的领域，并说明为什么它们可能相关。
5）区分表面相似和底层机制真正相似。
6）对最有价值的领域，找出可以迁移到当前问题中的具体方法，而不是只给概念。
7）判断哪些跨领域方法值得实际尝试，哪些只是有趣但没有实际价值。

如果你发现我其实不需要跨领域，而应该先深入当前领域，也请直接告诉我。
目标不是让我知道更多领域，而是找到可能改变解决方案的外部方法。
```

## 增加研究高度

```
你觉得我现在关心的这件事，如何能给全人类带来更高的意义？帮我从“为什么要做这件事？”开始，向上追问几层，寻找更高层的目标，但要避免假大空的泛泛目标。
```
