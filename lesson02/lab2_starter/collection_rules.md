# 社媒数据采集规则

把下面这一节原样复制进你项目的 CLAUDE.md。

```markdown
## 社媒数据采集规则
- 登录由我完成：打开登录页时停下，等我扫码后再继续。不要索要、保存或在任何文件里写入账号密码。
- 遇到验证码或风控提示，立刻停止并告诉我，不要尝试绕过。
- 每次页面操作之间间隔 3 秒以上；单次采集总量不超过 600 条。
- 只采集开场提示里列出的字段，其他信息（包括 IP 属地）不采。
- 原始数据存为带日期的文件，放在 data/raw/，只读，不提交到 Git。
- 浏览器的登录状态、cookie 文件不得放进项目文件夹，也不得提交到 Git。
- 清理时用户名、用户 ID 必须替换为哈希值；data/processed/ 和 output/ 里不得出现可直接识别个人的信息。
- 采集结束后写 COLLECTION_LOG.md。
```

这些规则是写给智能体的“请求”，它通常会遵守，但不能保证。`.gitignore` 和第 3 课要讲的 deny 规则才是强制手段。
