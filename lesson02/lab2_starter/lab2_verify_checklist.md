# 第 2 课验收清单

逐项自查。全部打勾后再进入第 3 课。

- [ ] 在一个全新的文件夹里，按 README 能从原始文件重跑到最终的图（采集这一步可以跳过，从 `data/raw/` 里的文件开始）
- [ ] 开场提示用了六个部分，留痕部分没有删减；提示原文保存在 `prompts_used.md`
- [ ] `DATA_PROFILE.md` 写在第一张图之前，包含：一行是什么、唯一性检验（总行数和不重复组合数两个数字）、各字段缺失比例
- [ ] 样本量每变化一次，都在 DECISIONS.md 或运行输出里有一行：变化前、变化后、原因
- [ ] 画过原始序列，再做汇总
- [ ] 两个检查在看图之前写进了 README，并注明来源：
  - 检查一：`________________`
  - 检查二：`________________`
- [ ] 最终的图由脚本生成，没有只存在于聊天里的结果

标准档和进阶档另加：

- [ ] `COLLECTION_LOG.md` 记录了采集时间、关键词、排序、篇数和每篇条数、页面显示的评论数与实际采到的条数
- [ ] 随机抽 10 条评论，回到网页逐条找到了（记录找到几条）
- [ ] 用户名、用户 ID 已替换成哈希值；清理后的数据里没有可以直接识别个人的信息
- [ ] `.gitignore` 生效：运行 `git check-ignore data/raw/` 有输出；原始数据和登录信息都不在 Git 里
- [ ] 采集过程中没有绕过验证码，没有高频请求
