# 开场提示模板（六个部分）

照着改成你自己的版本，再一次性发给智能体。**第六部分“留痕”一字不删。** 发出前先在 Plan mode（Shift+Tab）里让它给计划，读完再执行。

---

## 版本 A：社媒评论（标准档、进阶档）

**数据：** 在小红书搜索关键词“【你的关键词】”，按【最多评论】排序，取前【20】篇笔记。

**采集：** 每篇最多收集【30】条一级评论（不含楼中楼回复），字段只要：笔记 ID、笔记标题、笔记发布时间、评论 ID、用户名、评论文本、点赞数、页面显示的评论时间、是否作者回复，以及采集时间。评论需要滚动加载时，滚动到不再出现新评论为止。每次操作之间间隔 3 秒以上。打开登录页时停下，等我扫码后再继续；遇到验证码立刻停止并告诉我。原始数据存为 `data/raw/xhs_【日期】.json`。采集结束后写 `COLLECTION_LOG.md`：采集时间、关键词、排序、篇数、每篇页面显示的评论数和实际采到的条数、遇到的问题。

**清理：** 写 `scripts/clean.py`，从原始文件开始。以（笔记 ID，评论 ID）去重；把“3 天前”“昨天 18:20”“10-12”这类时间按采集时间换算成日期；去掉表情代码；用户名替换为哈希值；作者回复【保留/剔除】。

**测度：** 评论是否提到【价格】【品质】【信任】三类词。词表写进 `DECISIONS.md`。

**汇总与产出：** 按月统计评论数，画图存为 `output/comments_by_month.png`；三类词占比存为 `output/topic_share.csv`。图要适合放进工作论文：白底、坐标轴有中文标签、不用绘图库默认样式。

**留痕：** 每一步都写成有名字的脚本，不要只在聊天里给出结果。在做任何测度或画任何图之前，先写 `DATA_PROFILE.md`：一行是什么；以（笔记 ID，评论 ID）检验唯一性，报告总行数和不重复组合数；各字段缺失比例；时间字段有哪些格式；每篇实际采到的条数与页面显示的评论数对比。随做随写 `DECISIONS.md`，记录每一个方法上的选择和理由。随做随写 `LOG.md`，每个主要步骤一行，带时间。样本量每变化一次，打印一行：变化前、变化后、原因。

## 版本 B：世界银行（基础档）

**数据：** 用世界银行 API 下载【中国】【1991–2024】年的两个指标：农业就业占比 SL.AGR.EMPL.ZS 和人均 GDP（2015 年不变价美元）NY.GDP.PCAP.KD。原始数据存到 `data/raw/`。

**采集：** 写 `scripts/download.py` 完成下载，不要手动下载。

**清理：** 写 `scripts/clean.py`，把两个指标按国家-年份合并，报告合并前后的行数；缺失值保留为空，不要填 0。

**测度：** 人均 GDP 取自然对数。

**汇总与产出：** 画一张图存为 `output/structural_change.png`：横轴是对数人均 GDP，纵轴是农业就业占比，点按年份连线，标出起止年份。图要适合放进工作论文。底层数据存为 `output/structural_change.csv`。

**留痕：** （与版本 A 相同，一字不删）每一步都写成有名字的脚本，不要只在聊天里给出结果。在做任何测度或画任何图之前，先写 `DATA_PROFILE.md`：一行是什么；唯一性检验，报告总行数和不重复组合数；各字段缺失比例。随做随写 `DECISIONS.md` 和 `LOG.md`。样本量每变化一次，打印一行：变化前、变化后、原因。
