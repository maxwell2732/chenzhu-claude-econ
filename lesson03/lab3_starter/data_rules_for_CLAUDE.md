
## 授权数据规则（第 3 课）
- data/raw/ 是只读的原始数据，任何情况下都不得修改、移动、删除或覆盖。清理结果写到 data/intermediate/ 或 data/processed/。
- 不要在对话里打印大段原始记录。需要了解数据时，读变量名、变量标签、汇总统计，或者写脚本在本地计算后只报告汇总结果。
- 不读取、不输出姓名、住址、电话等可直接识别个人的字段。
- 原始数据和清理后的个体数据都不得提交到 Git。
- 找变量时先只读元数据（pyreadstat 的 metadataonly=True），不要为了看变量名而读入整份数据。
- 每次合并都打印报告：左表、右表、合并后的行数，匹配、只在左边、只在右边的数量；写明合并关系并用 validate 参数检查。
- 遇到含义不确定的编码（特殊缺失码、多选题、各轮次不一致的变量），停下来问我，不要自己猜。
- codebook 必须有 description 列，定义从 Stata 变量标签读取；新造的变量写明定义、来源和规则。
- 使用一个变量之前，先报告它在每一轮的非缺失数和取值分布，不要只根据问卷或变量说明判断它能用。
- 任何删除观测或改变合并方式（例如从左连接改成内连接）的操作，都要打印前后行数，并写进 DECISIONS.md。不要为了让代码跑通而悄悄删行。
