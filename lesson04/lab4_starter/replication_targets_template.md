## 复现范围

表【X】第【Y】列：【结果变量】对【关键解释变量】的回归。

设定：【模型类型】；控制变量：【列出】；样本：【筛选条件】；标准误：【类型和聚类层级，论文没写就写“论文未说明”】。

## 目标

| 目标 | 出处 | 论文值 | 容差 | 容差类型 | 为什么定这个容差 |
| --- | --- | --- | --- | --- | --- |
| 关键系数 | 表 X 第 Y 列 | | | abs | |
| t 值或标准误 | 表 X 第 Y 列 | | | abs | |
| 样本量 | 表 X 第 Y 列 | | | rel | |

容差的参考：

- 系数：一般取论文报告精度的一半到一个单位，或者和论文值差在一个标准误以内；方向必须一致。
- 样本量：取决于数据版本是否相同。同一版本建议 1% 以内；版本不同可以放宽，但要写出原因。
- 论文本身不显著的系数：目标是“同样不显著，方向不作要求”，在 note 里写明。

## 已知会有差异的地方

事先知道的写在这里，例如数据版本不同、某个变量找不到、论文没写标准误类型。
