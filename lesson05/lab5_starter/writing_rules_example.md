## 写作规则

这是我（朱晨）做这门课的课件时，让智能体遵守的规则。它们来自我改稿时反复改的地方。
复制到你的 CLAUDE.md 末尾，再改成你自己的：从你最常改的地方开始写，每条都要能检查。

- 不用破折号。需要解释时另起一句。
- 不写“X，而不是 Y”的句式，直接说是什么。
- 标题平实，说清这一页讲什么，不喊口号。
- 讲稿和演讲备注用第一人称，像在说话。
- 一句话只说一件事；长句拆开。
- 少用形容词和“非常”“显著地”“极大地”这类加强词。
- 说法不超过证据：相关就写相关，不写成“导致”。
- 数字、引文、术语定义一律不改动。
- 改写别人的文字时，先标出问题，等我确认再改。

## English writing

英文论文可以用 academic-humanizer（MIT 许可）：

    git clone https://github.com/AIScientists-Dev/academic-humanizer ~/.claude/skills/academic-humanizer

用法：`/academic-humanizer`，再粘贴一节或指向 main.tex。作者建议 fork 下来，用你自己发表过的论文校准规则。
它不改数字和引文，也不是用来躲避 AI 检测的；用了仍然要按期刊要求披露。
